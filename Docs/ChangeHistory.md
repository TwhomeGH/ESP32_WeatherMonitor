## 2026.10.13 21:45 ntfy 支援多組通知目標與獨立測試

**類型**: 功能 · **檔案**: `ntfy_test.cpp`

### 問題 - 單一主題無法分開管理接收群組

不同裝置或群組需要獨立的主題、權杖及測試操作。

### 修改 - 新增最多 8 組通知目標

- Web 可新增、編輯、刪除及啟停目標，各組可獨立發送測試通知。
- 舊主題與權杖自動移轉；所有目標持久儲存在 ESP32。
- 天氣通知依序送往所有啟用目標；部分成功不會誤報全部成功，也不會整批自動重送。
- 防止重複主題與同時建立多條通知 TLS 連線，權杖不由 API 回傳。
- 更新內建使用說明，加入多組操作流程與限制。
- 新增 .changelog.toml，使用 ChangeLogTools 建立本次更新紀錄。

### 驗證 - 網頁操作與修改檔案語法檢查通過

- 模擬測試涵蓋新增、選取、未儲存禁止測試、個別測試、停用、刪除失敗、刪除成功、8 組上限與安全呈現名稱。
- 內嵌設定頁、腳本及使用說明解壓後與來源一致。
